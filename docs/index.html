Dental practice software

Lustre Clinic

Appointment, record and payment software for a single dental practice. The clinic's records live on a computer in the clinic; an encrypted copy goes each night to the doctor's own Google Drive so the practice survives losing that computer.

Lustre is not a public product. It is not sold, not listed on any app store, and cannot be signed up for. It runs for one practice, on hardware that practice owns, and is used by its dentist and secretary.

How it is put together

Two Android phones talk to a small server in the clinic over a private network. There is no public website, no shared cloud database, and no account system — reaching the server at all requires being on the practice's private network.

Patient records never leave that server except as an encrypted backup, described below.

What it uses a Google account for

One thing only: putting the nightly backup somewhere that is not the clinic. A fire, a theft or a failed disk should not end a practice's records, and the off-site copy is what prevents that.

  • Lustre asks for a single Google permission, drive.file. That permission lets an app see and manage only the files it created itself — it cannot list, open or alter anything else in the account's Drive.
  • It creates one folder, Lustre Clinic Backups, writes the nightly backup into it, and deletes old backups on a schedule so the folder does not grow forever.
  • Each backup is encrypted before it leaves the clinic computer, with a key that is not stored on that computer and is not known to Google or to the developer.

The dentist signs in once, with their own Google account, and can withdraw that access at any time from their Google account permissions.
